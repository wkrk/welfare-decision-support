# 시설 위도·경도 기반 행정동 매핑

## 사용 데이터
- `BND_ADM_DONG_PG.shp` + `.shx`, `.dbf`, `.prj`, `.cpg` : 25개 안산시 **행정동** 경계
- 같은 `data/`에 원본 7개 CSV와 다음 보조 CSV를 둡니다.
  - `의료기관_위도와경도(1).csv`
  - `사회복지시설_위도와경도(1).csv`
  - `사회복지관_위도와경도(1).csv`
  - `보건지소_위도와경도(1).csv`
  - `공원_위도와경도(1).csv`
  - `구급약품_위도와경도(1).csv`

## 연결 방식
- 시설명 공백을 정규화하여 **원본과 보조자료 양쪽에서 유일한 이름만** 1:1 연결합니다.
- 동일한 시설명이 여러 번 등장하면 잘못된 좌표 연결을 방지하기 위해 주소 및 직접 검토 대상으로 남깁니다.
- 위도·경도는 WGS84(`EPSG:4326`)로 입력하고 행정동 SHP와 GeoPandas `sjoin`으로 연결합니다.
- 좌표가 없지만 보조자료에 행정동(`ADM_NM`)이 있다면 **잠정 매핑**으로 기록합니다.
- 매핑 실패 시 기존 주소 추정 방식을 사용하나 잠정 매핑으로 표시합니다.
- 원본 자료의 시설 개수와 좌표 보조자료의 시설 개수는 다를 수 있습니다. 최종 분모는 반드시 원본 건수입니다.

## 제공된 자료로 검증한 결과
| 종류 | 확인 | 잠정 | 미매핑 | 전체 |
|---|---:|---:|---:|---:|
| 의료기관 | 963 | 18 | 12 | 993 |
| 노인복지시설 | 3 | 0 | 0 | 3 |
| 사회복지관 | 5 | 0 | 0 | 5 |
| 보건시설 | 7 | 1 | 1 | 9 |
| 공원 | 80 | 0 | 0 | 80 |
| 상비약 판매업소 | 268 | 237 | 132 | 637 |

**중요:** 좌표가 경계 내부에 있었다는 의미의 '확인'이며, 좌표 원천의 실제 시설 위치까지 현장 검증했다는 뜻은 아닙니다. 특히 상비약 판매업소의 좌표 CSV는 270행으로 원본 637행보다 훨씬 적으므로 나머지는 별도 지오코딩과 수동 검토가 필요합니다. 본 계산은 외부 주소 API를 호출하지 않습니다.

## 실행
`python -m welfare_analysis.main --data-dir data --output-dir outputs`
