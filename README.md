# 안산시 공공데이터 기반 복지시설 배분 의사결정 지원

Python, GeoPandas, PCA, K-Means 및 정책 시뮬레이션을
활용한 데이터 기반 의사결정 지원 프로젝트입니다.

## 프로젝트 목적

안산시 25개 행정동의 고령인구 및 복지시설 자료를
통합하고 지역별 특성을 비교합니다.

제한된 시설 공급 조건에서 대안별 결과를 분석하여
의사결정에 필요한 기초자료를 제시합니다.

## 분석 구조

1. 공공데이터 수집 및 데이터 품질 확인
2. 시설 주소·좌표와 행정동 경계 공간조인
3. PCA 및 K-Means 기반 지역 특성 분석
4. 별도 시설부족지수 설계
5. 시설 총 5개 배분 대안 비교
6. 지도 및 HTML 보고서 생성

## 주요 기술

- Python / pandas / NumPy
- GeoPandas / Shapely
- scikit-learn / PCA / K-Means
- Matplotlib / Folium
- pytest

## 핵심 결과

- 25개 행정동 분석
- 75개 단일 지역 시설 확충 시나리오
- 효율성, 수요 가중, 취약지역 우선 3개 배분 대안 비교
- 총 5개 시설 추가, 행정동별 최대 3개 제약
## 주요 문제 해결 경험

### 1. 데이터 품질 검증

시설 데이터의 주소와 좌표를 행정동 경계에 연결하는 과정에서 매핑의 신뢰도 차이를 확인했습니다. 이에 따라 시설별 매핑 상태를 확인·잠정·미매핑으로 구분하고 데이터 품질을 별도로 기록했습니다.

### 2. 분석 방법의 한계 발견 및 개선

초기에는 PCA 기반 취약도 점수를 시설 확충 시나리오 평가에도 활용했습니다. 그러나 PCA 점수는 시설 증가에 따른 정책 효과를 직접 설명하기 어렵다는 한계를 확인했습니다.

이에 PCA와 K-Means는 지역 특성 분석 목적으로 유지하고, 시설 배분 대안 비교에는 별도의 정책 시설부족지수를 설계해 적용했습니다.

### 3. 의사결정 대안 비교

가상 시설 5개를 추가하는 동일한 조건에서 효율성 우선, 수요 가중, 취약지역 우선의 세 가지 배분 방식을 비교했습니다.

효율성 우선 방식은 총 시설부족지수 개선량이 더 컸으며, 취약지역 우선 방식은 시행 후 최대 부족지수를 더 낮추는 결과를 보였습니다.

이를 통해 제한된 자원 아래에서 의사결정 기준에 따라 선정 지역이 달라질 수 있음을 확인했습니다.
